# science_bingo

**クリスマス版**：雪の結晶が降る背景、電飾、オーナメント風の表示、鈴とジングルベルの効果音を使っています。クリスマス前の化学テーマ版は git の最初のコミット（c06934f）にあります。

`../simple_bingo` の機能はそのままに、デザインと演出を「化学ラボ」風に作り直したWebアプリ集です（ビンゴ・くじ引き・クイズ）。
HTML / CSS / JavaScript のみで作っており、ビルドは不要です。`index.html` をブラウザで開くだけで動きます。

## 1. bingo-app — XMAS ELEMENT BINGO（クリスマス元素ビンゴ）
抽選した番号を **原子番号** として扱い、周期表タイル（番号・元素記号・和名・分類）で表示します。

- **範囲指定**：最小値と最大値の範囲内で抽選します（初期値は1〜75）。当選済みの番号は出ません。
- **ルーレット演出**：約2.6秒かけて減速し、0.4秒止めてから当選番号を表示します。表示時はフラッシュ、衝撃波、分子風のパーティクル、効果音が出ます。
- **任意番号追加**：指定した番号を当選に加えます。範囲外の番号や当選済みの番号は、入力欄の下にエラーを表示します。
- **過去当選番号**：元素タイルで一覧表示し、「n / 全数 抽選済み」も表示します。
- 範囲が1〜75のときは、タイルにBINGOの列（B/I/N/G/O）も表示します。

## 2. lottery-app — XMAS REACTION LOTTERY（クリスマス化学反応くじ）
1等は金（Au）、2等は銀（Ag）、3等は銅（Cu）の試験管で表します。

- **1〜3等のくじ引き**：各等の当選人数を設定し、「設定を反映」を押します。
- **抽選確率**：各等の残数に比例します（残り枠1つにつき候補1つ。元アプリと同じ方式です）。
- **残数表示**：試験管の液面と泡の数、「残り n」の数字で残数を示します。
- **除外処理**：残数が0の等は当たりません。すべての枠が埋まると、抽選ボタンが押せなくなります。
- **当選履歴**：抽選した順に一覧表示します。
- **演出**：等級に応じて派手さが変わります。1等では紙吹雪が約5秒降り、画面が揺れ、ファンファーレが鳴ります。

## 3. quiz-app — XMAS LAB QUIZ（クリスマス化学クイズ）
イベントの途中で行うクイズ用の画面です。次の3画面を繰り返します。

1. **待機画面**：TV番組のアイキャッチ風に「第N問」を表示します。
2. **問題画面**：画面上部の帯に、問題文を先頭から1文字ずつ流します。中央に画像を出し、選択肢があればその下に並べます。
3. **正解画面**：「正解は…」と溜めたあと、正解を大きく表示します。選択肢がある問題では正解に ✓ を付け、解説も表示します。

画面左端のレールで、全体の何問目かがわかります（スマホ幅では画面上部に表示）。
操作は画面のボタンか、Space / Enter / →（進む）と ←（戻る）で行います。

### 問題の入れ替え
`quiz-app/questions.js` を書き換えます。画像は `quiz-app/images/` に置いてください。

```js
window.QUIZ = { title: 'クイズ名', questions: [
  { question: '問題文', image: 'images/q1.svg', answer: '正解', choices: ['A', 'B', 'C', 'D'], explanation: '解説' },
] };
```
`image`、`choices`（2〜4個）、`explanation` は省略できます。
同じ形のJSONファイルは、待機画面の「問題ファイルを読み込む」から読み込むこともできます。

## 共通の操作
- スピーカーボタン：効果音のオン/オフ（設定はブラウザに保存されます）
- 四隅のボタン：全画面表示（プロジェクターでの表示向け）
- Space / Enter キー：抽選（入力欄やボタンにフォーカスがないとき）

## デザイン方針
デジタル庁デザインシステムとWCAG 2.2 AAを参考にしています。

- 文字のコントラストは4.5:1以上にしています。
- キーボード操作の位置がわかるよう、フォーカス表示を常に出します。
- ボタンは高さ48px以上にしています。
- エラーは `alert()` ではなく、入力欄の近くに文章で表示します。
- 色だけで情報を伝えず、文字やアイコンも併記しています。
- OSで「視差効果を減らす」を設定している場合は、演出を控えめにします。

## 必要環境
- モダンブラウザ（Chrome / Edge / Firefox / Safari）
- インターネット接続は不要です。
- Windows / Mac のどちらでも同じ見た目になるようにしています。
  - 英数字フォント（Orbitron、JetBrains Mono）は各アプリの `fonts/` に同梱しています（SIL OFL）。
  - 日本語フォントは、ネット接続時は Google Fonts の Zen Kaku Gothic New を使います。未接続のときは Windows 標準の BIZ UDPゴシック／游ゴシックで表示します。
  - アイコンや飾りに絵文字は使わず、すべて SVG で描いています。
